```
사용자의 요청이 들어와서 응답이 나가기까지,
어떤 컴포넌트(서버, DB, 캐시 등)들이 어떻게 배치되고 서로 통신하는가?를 말한다.


요청 경로 (사용자 -> 서버)
- 클라이언트 (브라우저, 모바일 앱)
- CDN (정적 파일 캐싱, 예: CloudFront)
- 로드 밸런서 / 리버스 프록시 (Nginx, ALB)
- 웹/API 서버 (Spring Boot, NestJS, Next.js 서버)

데이터 계층
- RDB (MySQL, PostgreSQL), 필요하면 읽기 전용 Replica
- 캐시 (Redis)
- 파일 스토리지 (S3)

비동기 / 보조 요소
- 메시지 큐 (Kafka, RabbitMQ, SQS) -> 무거운 작업을 뒤로 미룰 때
- 배치/워커 서버
- 외부 API (결제, 소셜 로그인, 알림)

운영 요소
- 인증/인가 방식 (세션 vs JWT, 어디서 검증하는지)
- 모니터링, 로깅, CI/CD
- 배포 환경 (EC2, 컨테이너, 쿠버네티스, 서버리스)
```
