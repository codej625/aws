# 시스템 아키텍처

<br />
<br />

시스템 아키텍처란 무엇일까?

---

```
사용자의 요청이 들어와서 응답이 나가기까지,
어떤 컴포넌트(서버, DB, 캐시 등)들이 어떻게 배치되고 서로 통신하는가?를 말한다.


요청 경로 (사용자 -> 서버)
- 클라이언트 (브라우저, 모바일 앱)
- CDN (정적 파일 캐싱, 예: CloudFront)
- 로드 밸런서 / 리버스 프록시 (Nginx, ALB)
- 웹/API 서버 (Spring Boot, NestJS, Next.js 서버)

데이터 계층
- RDB (MySQL, PostgreSQL), 필요하면 읽기 전용 Replica
- 캐시 (Redis)
- 파일 스토리지 (S3)

비동기 / 보조 요소
- 메시지 큐 (Kafka, RabbitMQ, SQS) -> 무거운 작업을 뒤로 미룰 때
- 배치/워커 서버
- 외부 API (결제, 소셜 로그인, 알림)

운영 요소
- 인증/인가 방식 (세션 vs JWT, 어디서 검증하는지)
- 모니터링, 로깅, CI/CD
- 배포 환경 (EC2, 컨테이너, 쿠버네티스, 서버리스)
```

1. 좋은 아키텍처란?

```
시스템 아키텍처에 정답은 없다.

규모에 맞게, 필요한 만큼 과하지 않게 설계한 아키텍처가 가장 좋은 아키텍처이다.

왜냐면 시스템 아키텍처는 결국 돈과 직결되기 때문이다.

다만 요즘은 수직 확장보다는 수평확장을 많이 선호하는 편인데,
하나의 큰 인스턴스는 고정비용이 많이 들고 리소스가 낭비될 수 있기 때문이다.
```

2. AWS Well-Architected 6대 원칙

```
AWS에서 제공하는 "아키텍처를 잘 설계했다."라는 기준이 있다.

운영 우수성, 보안, 신뢰성, 성능 효율성, 비용 최적화, 지속 가능성 등을
중요한 요소로 본다.
```

<br />

`운영 우수성 원칙`

```
시스템을 실행하고 모니터링하여 비즈니스 가치를 제공하고,
지원 프로세스와 절차를 지속적으로 개선할 수 있는 환경

- 코드로서의 인프라
- 자동화된 배포 및 롤백
- 환경 모니터링
- 문서화 및 절차 표준화
- 장애에서 학습하고 개선하는 문화

-> CloudFormation, CloudWatch 
```

<br />

`보안 원칙`

```
데이터, 시스템, 자산을 보호하면서 클라우드 기술을 활용해 비즈니스 데이터를 지키고 관리하는 환경

- 강력한 자격 증명 기반 구축
- L7 전 계층에서의 보안 확립
- 전송과 저장 시 데이터 암호화
- 보안 이벤트에 대한 저장 관리
- 보안 위협에 대한 즉각적 대응 시스템 마련

-> IAM, VPC, WAF, Security Groups, KMS 등
```

<br />

`신뢰성 원칙`

```
시스템이 장애로부터 복구하고, 수요에 맞춰 컴퓨팅 리소스를 동적으로 확보하며
구성 오류나 일시적 네트워크 문제 등의 중단을 완화하는 능력

- 장애 복구 자동화
- 수평적 확장을 통한 전체 시스템을 가용성 증대
- 용량 추정 중단
- 변경 관리 자동화

-> Multi-AZ, AutoScaling Group, LoadBalancer
```

<br />

`성능 효율성 원칙`

```
컴퓨팅 리소스를 효율적으로 사용하여 시스템 요구 사항을 충족하고,
수요 변화와 기술 발전에 따라 효율성을 유지하는 능력

- 몇 분 만에 전 세계 배포
- 기술의 대중화
- 서버리스 아키텍처

-> Cloudfront, Lambda, Serverless, Fargate
```

<br />

`비용 최적화 원칙`

```
불필요한 비용이나 비효율적인 리소스를 피하고 최저 가격으로 시스템을 실행하는 능력

- 전반적인 호율성을 측정할 수 있는 가시성 확보
- 차별화되지 않은 작업에 대한 비용 지출을 확인하고 즉각 중단할 수 있는 환경
- 리소스 사용량을 확인하고 지속적으로 줄일 수 있는 환경

-> Reserved Instance, Spot Instance, S3 Tiering, Cost Explorer
```

<br />

`지속 가능성 원칙`

```
클라우드 워크로드 실행의 환경적 영향을 최소화하는 환경

- 더 효율적인 하드웨어 및 소프트웨어 개선 및 발굴
- ESG 지속가능성 목표 설정

-> Gravition, Carbon Footprint
```
