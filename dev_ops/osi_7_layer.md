# OSI 7 Layer Model

<br />
<br />

* OSI 7계층?

---

```
네트워크 통신이 일어나는 과정을 7개의 단계로 나눠서 설명하는 표준 참조 모델이다.

1984년 ISO(국제표준화기구)가 만들었고,
서로 다른 제조사의 장비나 시스템이 통신할 수 있도록 "각 단계가 무슨 역할을 하는지"를 정리한 것이다.

여기서 가장 많이 언급되고 중요하게 보는 Layer는 L4, L7이다.
```

1. 프로세스 예시

```
웹을 다루는 개발자 관점에서,
레이어를 알아보자.
```

<br />

| 계층 | 이름 | 웹 개발자 관점에서의 대응 | 예시 |
|---|---|---|---|
| 7 | 응용 (Application) | Spring Boot, Nest, Next에서 다루는 HTTP 요청/응답, REST API, 쿠키, 헤더. L7 로드밸런서도 HTTP 내용을 보고 분산하므로 이 계층 | HTTP, REST API, Nginx, AWS ALB |
| 6 | 표현 (Presentation) | HTTPS의 TLS 암호화, JSON 직렬화/역직렬화, 문자 인코딩 | TLS, JSON, UTF-8 |
| 5 | 세션 (Session) | 로그인 세션, WebSocket 연결 유지. 실제로는 애플리케이션이 처리하는 경우가 많아 TCP/IP에서는 7계층에 합쳐 봄 | 세션, WebSocket |
| 4 | 전송 (Transport) | 서버가 8080 같은 포트를 열고 TCP로 연결을 받는 부분. 포트 충돌이 이 계층 문제. L4 로드밸런서, 포트 기반 방화벽 규칙, 클라우드 보안 그룹도 여기에 걸침 | TCP, UDP, AWS NLB |
| 3 | 네트워크 (Network) | IP 주소 기반 라우팅. 라우터, 라우팅 테이블, IP 대역 단위 방화벽 규칙 | IP, ICMP(ping), 라우터 |
| 2 | 데이터 링크 (Data Link) | 같은 네트워크 안에서 MAC 주소로 프레임 전달. 개발자가 직접 다룰 일은 거의 없음 | 이더넷, 스위치, ARP |
| 1 | 물리 (Physical) | 실제 전기/광/무선 신호 전송. 네트워크 장비와 인프라 영역 | 랜선, 광케이블, Wi-Fi |

<br />

```
        OSI 7 Layer Model                        TCP/IP Protocol
  ┌─────────────────────────────┐        ┌─────────────────────────────────┐
7 │ Application Layer           │        │                                 │
  ├─────────────────────────────┤        │  Application                    │
6 │ Presentation Layer          │        │  (HTTP, FTP, SMTP, DNS, DHCP,   │
  ├─────────────────────────────┤        │   TFTP, SNMP, Telnet)           │
5 │ Session Layer               │        │                                 │
  ├─────────────────────────────┤        ├─────────────────────────────────┤
4 │ Transport Layer             │        │  Transport  (TCP, UDP)          │
  ├─────────────────────────────┤        ├─────────────────────────────────┤
3 │ Network Layer               │        │  Internet                       │
  │                             │        │  (IP, ICMP, ARP, RARP)          │
  ├─────────────────────────────┤        ├─────────────────────────────────┤
2 │ Data Link Layer             │        │                                 │
  ├─────────────────────────────┤        │  Network Interface              │
1 │ Physical Layer              │        │                                 │
  └─────────────────────────────┘        └─────────────────────────────────┘
```
