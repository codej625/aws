# AWS 서비스

<br />
<br />

* AWS에서 제공하는 여러 가지 서비스

---

```
AWS는 기존 호스팅을 위해 필요한 모든 물리적인 요소를
클라우드 서비스로 제공한다.

클라우드를 사용하지 않는 회사에서 근무 중인 개발자들도 많기에
어떤 서비스가 어디에 해당하는지 알아보자.
```

<br />
<br />
<br />
<br />

1. EC2

```
컴퓨팅 하드웨어를 원하는 만큼 빌려 사용한다.

쉽게 말하면 AWS에서 자신의 서버를 VM 형태로 제공하는 것이다.

VM으로 실제 떠 있는 서버를 인스턴스 (Instance)라고 말한다.
```

<br />
<br />
<br />

2. S3

```
이미지나 여러 파일에 대한 저장공간.

클라우드 저장소라고 보면 된다.
```

<br />
<br />
<br />

3. RDS

```
데이터 저장 DB를 빌려주는 서비스.

원래는 인스턴스를 빌리고 운영체제를 설치하고,
DB 서버를 구축하겠지만, 클라우드에 편의성을 더해
곧바로 사용할 수 있는 DB 서버이다.
```

<br />
<br />
<br />

4. Route53

```
Domain Name System (DNS) 을 빌려주는 서비스.

우리가 많이 사용하는 가비아처럼 도메인을 구입하고, DNS를 다룬다.
```

<br />
<br />
<br />

5. VPC

```
격리된 네트워크를 빌려주는 서비스.

VPC(Virtual Private Cloud)는 AWS 안에 만드는 나만의 가상 네트워크이다.

EC2, RDS같은 리소스는 전부 VPC 안에 배치되고,
IP 대역, 서브넷, 라우팅, 방화벽 규칙을 설계한다.

VPC CIDR -> (VPC 전체 IP 대역) 을 설정하고, 서브넷 (VPC를 쪼갠 IP 대역)을 설정한다.
```
